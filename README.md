# 📱 TransporteSL

> **Proyecto de aprendizaje de Android moderno desarrollado como parte de mi proceso de actualización profesional.**

## 📖 Descripción

**TransporteSL** es una aplicación Android desarrollada con el objetivo de aprender las tecnologías y buenas prácticas actuales del desarrollo móvil.

El proyecto forma parte de mi portfolio personal y documenta, paso a paso, mi regreso al desarrollo de software después de varios años alejado del trabajo profesional.

Más que construir una aplicación, el objetivo es construir una base técnica sólida.

---

## 🎯 Objetivos del proyecto

* Aprender desarrollo Android moderno.
* Dominar Jetpack Compose.
* Aplicar buenas prácticas de arquitectura y organización del código.
* Incorporar Git y GitHub como herramientas de trabajo desde el inicio.
* Construir un proyecto real que refleje una evolución constante.

---

## 🛠️ Tecnologías

* Kotlin
* Android Studio
* Jetpack Compose
* MapLibre Compose
* OpenStreetMap (OSM)
* OpenFreeMap
* Git
* GitHub

> Esta lista irá creciendo a medida que el proyecto evolucione.
